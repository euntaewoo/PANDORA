## 💡 0. 핵심 실무 주의사항 (왜 HTML 모드가 아닌 에디터 모드인가?)

1. **지마켓/옥션(ESM Plus)의 작동 특성**:
   - PC에서 드래그하여 등록한 상세페이지 이미지들은 **`에디터 작성` 탭**에 배치되어 있습니다.
   - 이때 상단의 **`HTML 작성` 탭으로 전환하게 되면, 기존 에디터에 올려둔 모든 이미지가 초기화(삭제)되는 치명적인 문제**가 발생합니다. (HTML로 하려면 모든 이미지를 호스팅 서버에 올리고 URL을 따야 하는 번거로움 발생)
2. **해결책**:
   - 이미지가 올라가 있는 **`에디터 작성` 탭 화면을 그대로 유지**한 상태에서,
   - `_VIEWER.html`의 **`[⚡ 에디터 서식 원클릭 복사]`** 버튼을 클릭하여 붙여넣으면, **이미지는 그대로 보존되면서 텍스트 줄바꿈/서식만 완벽하게 삽입**됩니다!

## 🚀 2. 지마켓 ESM 에디터 3초 완벽 등록 프로세스

1. 상품 폴더의 **`[상품명]_[국가]_SEO_GEO_AEO_VIEWER.html`** 파일을 더블클릭하여 엽니다.
2. **5줄 요약 등록**:
   - 뷰어의 2번 카드 우측 **`[⚡ 5줄 요약 서식 복사 (에디터 붙여넣기용)]`** 초록색 버튼 클릭.
   - 지마켓 **`에디터 작성`** 본문 원하는 위치에 마우스 커서를 두고 **`Ctrl + V`**.
   - ➔ **굵은 항목명과 문장별 줄바꿈이 완벽하게 쏙 들어감!**
3. **FAQ 등록**:
   - 뷰어의 3번 카드 우측 **`[⚡ FAQ 전체 서식 복사 (에디터 붙여넣기용)]`** 초록색 버튼 클릭.
   - 지마켓 **`에디터 작성`** 본문 하단에 마우스 커서를 두고 **`Ctrl + V`**.
   - ➔ **질문은 파란 볼드체, 답변 문장은 줄바꿈된 형태로 깨끗하게 자동 완성!**
4. **마우스 드래그 복사 지원**:
