## 🚀 2. 쇼핑몰 등록 탭별 원클릭 복사 가이드 (가장 중요!)

`[상품명]_[국가]_SEO_GEO_AEO_VIEWER.html` 파일을 더블클릭하여 크롬/엣지 브라우저에서 엽니다.

### 🌟 [방법 1] 'HTML 작성' 탭을 이용할 때 (강력 추천 ⭐⭐⭐⭐⭐)
> **적용 대상**: 지마켓/옥션(ESM Plus) `HTML 작성` 탭, 스마트스토어 `HTML` 모드, 카페24, 메이크샵 등

1. 뷰어 최상단의 **보라색 버튼 `[🚀 5줄 요약 + FAQ 전체 일괄 복사]`**를 클릭합니다.
2. 쇼핑몰 등록 시스템의 **`HTML 작성`** 탭을 클릭합니다.
3. 입력창에 그대로 **`Ctrl + V` (붙여넣기)** 합니다.
4. 쇼핑몰의 **`[미리보기]`** 버튼을 누르면:
   - **블루 톤의 럭셔리 카드 박스**,
   - **볼드 처리된 Q 질문 헤더**,
   - **문장별 엔터 줄바꿈과 쾌적한 문단 간격**이 100% 완벽하게 적용되어 즉시 완성됩니다!

---

### 📝 [방법 2] '에디터 작성' 탭 또는 일반 텍스트 모드를 이용할 때
> **적용 대상**: 지마켓/옥션 `에디터 작성` 탭, 쿠팡 상세설명 텍스트창, 11번가 일반 에디터 등

1. 뷰어의 각 섹션에 있는 **파란색 버튼 `[📋 에디터 작성용 텍스트 복사]`**를 클릭합니다.
2. 쇼핑몰의 **`에디터 작성`** 화면에 **`Ctrl + V` (붙여넣기)** 합니다.
3. **효과**: AI가 중국어 마침표(`。`), 영문 마침표(`.`)를 기준으로 **문장마다 엔터(줄바꿈)를 미리 쳐두었기 때문에, 가로 1줄로 뭉개지지 않고 줄 단위로 깔끔하게 입력**됩니다.
