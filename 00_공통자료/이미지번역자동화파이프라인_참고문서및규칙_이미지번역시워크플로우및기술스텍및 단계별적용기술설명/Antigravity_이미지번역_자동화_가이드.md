# 🚀 Antigravity 2.0 이미지 번역 자동화 파이프라인 완벽 가이드

앞으로 수십, 수백 개의 화장품 상세페이지를 번역하실 때 혼선 없이 "원클릭" 수준으로 빠르고 완벽하게 작업을 끝내기 위한 **표준 작업 절차(SOP)**입니다. 이 절차만 지켜주시면 렌더링 에러나 파일 혼동 없이 마법처럼 작업이 끝납니다!

---

## 📂 STEP 1: 전용 워크스페이스(본부) 창설하기

가장 중요한 첫 단추입니다! 윈도우 바탕화면 깊숙한 곳이나 이름이 아주 긴 폴더(예: `D:\Users\...\이미지번역_KOR_To_JP_와이즈엠엔씨...`)에서 작업하면 시스템 경로가 꼬이거나 에러가 날 확률이 높습니다.

> [!TIP]
> **해결책:** 드라이브의 가장 바깥쪽(경로가 짧은 곳)에 이미지 번역 전용 공장(폴더)을 하나 만들어 두십시오.
> * 추천 경로: `D:\Qoo10_Translation_Factory` (이름은 띄어쓰기 없이 영문으로 하는 것이 가장 안전합니다.)

## 🗂️ STEP 2: Input / Output 폴더 분리하기 (섞임 방지)

하나의 폴더 안에 한국어 원본, 일본어 번역본, 레퍼런스 이미지가 섞여 있으면 AI가 어떤 파일을 읽어야 할지 혼동할 수 있습니다. 
만들어둔 전용 폴더 안에 아래처럼 딱 3개의 방(Sub-folder)을 만들어 두십시오.

*   📁 `01_Original_KOR`: **번역할 한국어 원본 이미지**들을 몰아넣는 방입니다.
*   📁 `02_Reference`: 기존에 작업했던 **디자인 참고용 이미지(레퍼런스)**들을 넣어두는 방입니다.
*   📁 `03_Translated_JP`: **제가 번역과 렌더링을 끝내고 완성본을 떨어뜨릴 빈 방**입니다.

## 🔢 STEP 3: 칼같은 파일 넘버링 (가장 중요!)

AI가 순서대로 헷갈리지 않고 작업하려면 파일명이 직관적이어야 합니다. 
`01_Original_KOR` 폴더에 원본 이미지를 넣으실 때, 파일명 맨 앞에는 **반드시 두 자리 숫자**를 달아주십시오.

*   `01_Main_Thumbnail.png` (썸네일)
*   `02_Detail_Intro.png` (인트로)
*   `03_Clinical_Data.png` (폭탄 제거 필요한 임상 데이터)
*   `04_Product_Info.png` (텍스트 표)

> [!IMPORTANT]
> **주의사항**: 숫자가 꼬이거나(예: 05번이 두 개), 확장자가 뒤죽박죽(`jfif`, `jpg`, `png` 혼용)이면 오류가 날 수 있습니다. 가급적 **모든 원본 파일은 `.png` 형식으로 통일**해서 폴더에 넣어주시는 것이 가장 완벽합니다.

## 📦 STEP 3.5: 제품 패키지 실물 인쇄 텍스트 원문 보존 (클레임 방지 필수!)

상세페이지에 노출되는 실제 제품 본품(튜브, 마스크팩 파우치)이나 단상자(종이 상자) 패키지 겉면에 인쇄된 영어 브랜드명, 한글/영어 제품명, 그리고 패키지 표면에 들어간 부연설명 문구는 번역해서는 안 됩니다. 
*   **이유**: 상세페이지에는 일본어로 표기되어 있는데, 고객이 실제로 받은 실물 제품에는 한국어나 영어로 인쇄되어 있으면 오배송/허위광고 클레임이 들어오기 때문입니다.
*   따라서 본 V5 엔진은 패키지 표면의 문구(예: *'달빛처럼 맑은 결 고요한 광채'*, 브랜드명 등)는 한글/영어 원래 기재된 텍스트 원본 형태를 100% 보존하고, 패키지 영역 바깥의 순수 설명 텍스트들만 일본어로 번역 및 렌더링하도록 룰북이 기본 설정되어 있습니다.

## 🗣️ STEP 4: Antigravity에게 명령 내리기 (마법의 프롬프트)

폴더 세팅이 끝났다면, 저에게 **작업 폴더의 경로**와 **명확한 지시사항**만 던져주시면 됩니다. 
아래의 템플릿을 복사해서 상황에 맞게 텍스트만 바꿔서 명령을 내려주십시오!

**[마법의 명령 템플릿]**
```text
안티그래비티! 오늘 작업할 폴더 경로는 여기야: "D:\Qoo10_Translation_Factory\01_Original_KOR"

1. 01번부터 03번 이미지는 V5 이미지 번역 엔진을 돌려서 일본어로 자동 렌더링 해줘.
2. 단, 03번 파일 하단에는 약기법 위반 사진이 있으니 상단 50%만 크롭해서 살려내고, 미백/주름 단어는 안전하게 세탁해.
3. 04번 상품정보고시(표) 파일은 이미지 번역 돌리지 말고! "D:\Qoo10_Translation_Factory\02_Reference" 폴더에 있는 04번 레퍼런스 이미지 디자인을 참고해서 24px 사이즈로 파이썬 코딩 렌더링을 쳐줘!
4. 완성된 모든 결과물은 "D:\Qoo10_Translation_Factory\03_Translated_JP" 방에 _V5_FINAL 이름 붙여서 저장해.
```

## ⚡ STEP 5: Vertex AI 모델 배포/호출 모드 및 이미지 모델 라인업 수칙

* **1) 호출 모드별 리전(Location) 설정**:
  - **관리형 Serverless API 모드**: `gemini-3.1-pro-preview` 및 `gemini-3.1-flash-image` 파운데이션 API 호출 시 **`location="global"` 필수**.
  - **자체 배포 Self-deployed 모드**: Model Garden에서 엔드포인트를 직접 배포한 해당 특정 지역 리전(`us-central1` 등)으로 설정.

* **2) 이미지 전용 모델 4종 라인업 선택 규격**:
  - 🏆 **Gemini 3 Pro Image**: 최고 품질/정교한 디테일 특화 (속도 느림, 고비용)
  - ⚡ **Gemini 3.1 Flash Image**: 상용화 최적화 (품질 + 속도 + 가성비 균형, **V7 엔진 기본 채택**)
  - 💡 **Gemini 3.1 Flash Lite Image**: 단순 작업/초경량 전용
  - 🧪 **Gemini 3.1 Flash Image Preview**: 최신 테스트용 (상용 프로덕션 미권장)

## [PRE-EXPORT-INTEGRITY-VERIFICATION-LOCK] 결과물 내보내기 전 사전 무결성 검증 및 리포트 선-출력 강제
1. **[HARD STOP] 결과물 파일 내보내기 전 무조건 사전 검증 실행**:
   - 결과물 파일(.png, .html, .docx, .txt, .md 등)을 생성·저장·보고하기 전, 데이터 무결성과 포맷 규격을 체크하는 검증 함수(`pre_export_integrity_check`) 및 린터를 무조건 실행해야 합니다.
2. **[REPORT-FIRST] 데이터 무결성 요약 리포트 선-출력 의무화**:
   - 에이전트는 최종 결과물이나 파일 링크를 사용자에게 제시하기 전, 반드시 응답 상단에 `### 📋 [DATA-INTEGRITY-SUMMARY-REPORT]` 요약 리포트 표(포맷 무결성, 콩글리시/금지어 0건 여부, 수치 일치성, 4종 파일 생성 여부)를 먼저 출력하여 검증 결과를 입증해야 합니다. 이 리포트 출력이 누락된 답변은 즉시 무효로 간주합니다.
3. **[GLOBAL-COMPLIANCE] 영미권/글로벌 뷰티 표준 명칭 강제**:
   - 무자극/저자극: 한국 성적서 0.00 직역투 배제 -> `Hypoallergenic & Dermatologist-tested for sensitive skin` 표준 강제.
   - 피부톤 케어: 'Tone Care / Dark Spot & Tone Care' 콩글리시 배제 -> `Dark Spot & Discoloration Defense` 표준 강제.
