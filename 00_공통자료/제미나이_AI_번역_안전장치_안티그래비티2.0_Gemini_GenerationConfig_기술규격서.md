# [안티그래비티 2.0] 글로벌 뷰티 AI 초월번역 및 리스크 제어를 위한 하이퍼파라미터 가이드북
> **문서 상태**: 공식 기술 규격서 (GCP Vertex AI API 기반)  
> **최종 수정일**: 2026년 8월 22일  
> **적용 버전**: Antigravity 2.0 (Gemini 3.1 Pro 파이프라인)

---

## 1. 개요 및 정의 (Overview)

본 문서는 한글 출발어를 다국어(영어, 중국어 간체·번체, 일본어 등)로 초월번역(Transcreation)할 때 발생하는 **현지 화장품 광고법 위반 리스크(환각 현상 및 과장 표현)를 시스템 레벨에서 원천 차단**하기 위한 핵심 기술 규격을 정의합니다.

### 📌 핵심 개념 용어
인공지능 모델의 내부 연산 방식을 제어하기 위해 사용자가 외부 소스 코드나 API 세팅에서 직접 지정해 주는 조절 매개변수들을 **'LLM 하이퍼파라미터(Hyperparameters)'** 혹은 구글 공식 명칭으로 **'모델 생성 설정(Generation Configuration)'**이라고 호칭합니다. 이는 단순한 텍스트 지시(Prompt)를 넘어 AI 엔진이 글자를 조합하는 하드웨어적 규칙 자체를 강제로 고정(Binding)하는 물리적 안전장치입니다.

## 2. 4대 핵심 하이퍼파라미터 상세 해설 (Deep Dive)

안티그래비티 2.0 시스템의 `global_rules.md` 및 백엔드 파이프라인 코드(`multilingual_text_in_image_translatio_agy_sdk_core.py`)에 바인딩된 4대 핵심 변수의 상세 작동 원리는 다음과 같습니다.

### ① GenerationConfig 강제 바인딩 (Generation Configuration)
*   **정의**: 구글 Vertex AI API 규격 최상위 계층에 위치하는 하드웨어 규칙 모음입니다.
*   **해설**: AI에게 프롬프트(텍스트)로만 "광고법을 준수하라"고 명령하면, 특정 문맥에서 지시를 무시하고 헛소리를 뱉는 환각 현상(Hallucination)이 발생합니다. 이를 원천 차단하기 위해 엔진 자체의 텍스트 생성 매커니즘을 시스템 코드로 영구 잠금(Lock) 처리하는 행위를 의미합니다.

### ② "temperature": 0.6 (창의성과 법규 준수의 황금 비율)
*   **정의**: 생성되는 텍스트의 '창의성'과 '방종함'을 통제하는 확률적 온도 수치 (범위: 0.0 ~ 2.0).
*   **해설**: 
    *   **온도가 1.0 이상으로 높을 경우**: AI가 흥분 상태에 빠져 원문에 없는 `全球首創(세계 최초)`, `終極對策(종극대책)` 같은 자극적인 위법 단어를 무작위로 남발하여 대만 TFDA나 일본 약기법 적발 대상이 됩니다.
    *   **온도가 0.2 이하로 낮을 경우**: 지나치게 방어적으로 작동하여 딱딱한 백과사전식 기계 번역만 출력되므로 마케팅 카피의 매력이 소멸합니다.
    *   **0.6 설정의 의미**: 해외 광고법을 절대로 위반하지 않는 안전선을 유지하면서도, 소비자의 심리를 자극하는 프리미엄 초월번역을 도출해 내는 글로벌 최적의 밸런스 수치입니다.

### ③ "topP": 0.9 (럭셔리 뷰티 어휘 필터링)
*   **정의**: AI가 다음 단어를 선택할 때 누적 확률 분포 상위 90% 이내의 정제된 단어만 후보군으로 인정하는 샘플링 제한 규칙 (범위: 0.0 ~ 1.0).
*   **해설**: 
    *   **1.0인 경우**: 인터넷상에 떠도는 유치한 인터넷 용어, 비속어, 정형화되지 않은 싸구려 표현까지 전부 단어 후보에 포함하여 품질이 무너집니다.
    *   **0.9 설정의 의미**: 하위 10%의 부적절하거나 투박한 직역 투 표현들을 가차 없이 연산 단계에서 탈락시키고, 글로벌 백화점 브랜드의 상세페이지에 걸맞은 정제되고 고급스러운 럭셔리 뷰티 어휘들 중에서만 문장을 조형하도록 강제하는 필터 장치입니다.

### ④ "maxOutputTokens": 토큰 한도 안전 천장 (전역 8192 적용)
*   **정의**: AI가 한 번의 API 호출로 생성할 수 있는 최대 텍스트 글자 수(토큰) 제한 값의 안전 천장 규격.
*   **해설**: 
    *   **대용량 데이터 추출 및 고시표 번역 (Pass 1 & Table Render)**: `max_output_tokens=8192` (전성분 등 방대한 화학 명칭 및 JSON 구조 유실 방지)
    *   **마케팅 카피 및 SEO 생성 (SEO/GEO/AEO)**: `max_output_tokens=8192` (Thinking 토큰 잠식에 의한 Q4/Q5 잘림 방지 안전 천장 확보 + 프롬프트에서 FAQ 5개 및 간결 답변 엄격 제한)

## 3. 안티그래비티 2.0 환경별 적용 방법 (Implementation)

현재 시스템 환경과 인터페이스 유형에 맞춰 아래 방식 중 하나를 선택해 실제 인프라에 체결합니다.

### 🎯 방식 A. 안티그래비티 2.0 에이전트 대화창 직접 주입법 (현재 적용 방식)
안티그래비티 AI 에이전트 인터페이스의 하단 입력창(`Ask anything...`)에 백엔드 소스 코드 자동 수정을 명령하는 종합 스크립트를 전달합니다.

```text
현재 가동 중인 다국어 상세페이지 번역 파이프라인의 `GenerationConfig` 인스턴스를 아래 규격으로 강제 업데이트하고 코드를 수정해줘. 
API 호출 시 생성 설정 객체에 "temperature": 0.6, "topP": 0.9, "maxOutputTokens": 8192(전역 안전천장)를 바인딩하여 출력 잘림을 원천 차단하고 프롬프트에서 5대 FAQ 분량을 통제해야 해. 
수정이 완료되면 `multilingual_text_in_image_translatio_agy_sdk_core.py` 파일의 Git 커밋 로그를 리턴해줘.
```

### 🎯 방식 B. 백엔드 시스템 소스 코드 물리 주입법
개발 환경에서 구글 클라우드 Vertex AI SDK를 사용하여 엔진 레이어를 직접 구축할 경우, 호출 인스턴스 내부에 속성값으로 매핑합니다.

```python
# python 규격 예시 (Pass 1 고시표 및 SEO 전역 8192 안전천장)
from google.genai import types

# 1. 하드웨어 추론 파라미터 표준 주입 (8192 안전천장)
config = types.GenerateContentConfig(
    temperature=0.6,
    top_p=0.9,
    max_output_tokens=8192
)

# 2. 모델 인스턴스 선언 시점 결합
model = GenerativeModel(
    model_name="gemini-3.1-pro-preview",
    generation_config=generation_config,
    system_instruction="귀하는 글로벌 럭셔리 뷰티 카피라이터이며 현지 광고법 스크리닝 전문가입니다."
)
```

### 🎯 방식 C. REST API 직접 호출용 JSON 페일로드 규격
백엔드 서버에서 구글 버텍스 AI 엔드포인트 URL로 직접 HTTP POST 신호를 송신할 때 전송해야 하는 표준 JSON 데이터 구조입니다.

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{ "text": "Source Text: {{SOURCE_TEXT}}\nTarget Language: {{TARGET_LANG}}" }]
    }
  ],
  "generationConfig": {
    "temperature": 0.6,
    "topP": 0.9,
    "maxOutputTokens": 4096
  }
}
```
*(※ 주의: `generationConfig` 세팅 블록은 `contents` 배열 내부가 아닌, 반드시 그와 대등한 최상위 루트 계층에 위치해야 엔진 제어가 강제됩니다.)*

## 4. 기대 효과 (Business Impact)

1. **글로벌 컴플라이언스 완벽 통과**: 대만 TFDA(식품약물관리서), 중국 NMPA(국가약품감독관리국), 일본 PMDA(후생노동성)의 과대광고 모니터링 시스템을 우회하는 100% 합법적이고 안전한 상업용 카피 무한 생성.
2. **독보적인 프리미엄 품질 구현**: 직역 투 번역기가 아닌 현지 지사 탑클래스 카피라이터가 직접 쓴 수준의 유려하고 격식 있는 브랜드 뷰티 문맥 확보.
3. **인프라 비용 보존 및 속도 향상**: 불필요한 토큰 루프 출력을 막아 구글 인프라 API 청구 비용을 최소 30% 이상 절감하고 이미지 배치 렌더링 속도 대폭 개선.
