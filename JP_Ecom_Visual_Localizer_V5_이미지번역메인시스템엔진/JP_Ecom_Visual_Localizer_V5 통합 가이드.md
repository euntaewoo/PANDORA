# JP_Ecom_Visual_Localizer_V5 통합 가이드

본 문서는 **JP_Ecom_Visual_Localizer_V5** 일본 이커머스(Qoo10 Japan 등) 이미지 번역 및 현지화 시스템의 표준 작업 가이드라인입니다.

---

## 1. 시스템 핵심 기술 사양 (V5 Technical Specs)

*   **메인 번역 코어**: `JP_Ecom_Visual_Localizer_V5.py`
*   **번역 AI 엔진**: Gemini API `gemini-3.1-flash-image` (구형 모델 전면 셧다운에 따른 최신 이미지 재생성 규격)
*   **배경 복원 기술**: **Surgical Inpainting V5.0** (OpenCV Inpainting `INPAINT_NS` 및 NumPy Median 주변색 보존 복원)
*   **서체 바인딩**: **Noto Sans JP** (가변 폰트 `NotoSansJP-VF.ttf` 로컬 1순위 강제 바인딩)

---

## 2. 현지화 및 약기법 자동 대응 규격

본 V5 엔진은 일본 약기법(PMDA) 및 플랫폼 가이드라인 준수를 위해 번역 및 이미지 처리에 아래 규칙들을 자동으로 적용합니다.

### 2.1 주요 단어 매핑 룰 (필수 수치)
*   **"흡수"** ➔ **"浸透"**로 번역하며, 이 단어가 사용되면 이미지 하단에 자동으로 **`*浸透は角質層まで` (각질층까지 흡수됨)**이라는 일본 법적 필수 면책 문구를 1.2% 크기로 삽입합니다.
*   **"적당량"** ➔ **"500円玉大"** (동전 크기로 구체화)
*   **"컨디션 유지"** ➔ **"コンディション維持"**

### 2.2 약기법 금지어 세탁 필터
*   **의학적 효능 표현 정정**:
    *   `치료 (治療)` ➔ `ケア (케어)`
    *   `개선 (改善)` ➔ `整える (정돈하다)`
    *   `재생 (再生)` ➔ `いきいき (생생함/생기)`
*   **효능 단정성 표현 완화**:
    *   `자극 없이 / 무자극` ➔ `肌にやさしく (피부에 순하게)` 또는 `低刺激処方 (저자극 처방)`
    *   `진정 (鎮静)` ➔ `肌を整える (피부를 정돈하다)` 또는 `肌荒れを防ぐ (피부 거칠어짐을 방지하다)`

### 2.3 상품(제품) 패키지 실물 인쇄 텍스트 원문 보존 규칙
*   **정의**: 이미지 내에 포함되어 묘사된 실제 화장품 본품 용기(튜브, 병, 마스크팩 파우치 등) 및 제품 종이 포장 상자(단상자) 표면에 직접 인쇄된 모든 텍스트는 번역 대상에서 제외합니다.
*   **보존 대상**: 영어 브랜드명/로고, 영문 제품명, 용량 정보, 패키지 표면에 디자인 요소로 함께 인쇄된 한글 문장 및 설명문구 전체.
*   **이유**: 상세페이지 내 제품 이미지와 실제 고객이 수령하는 제품 패키지 실물 간의 텍스트 불일치로 인한 전자상거래(Qoo10, Rakuten 등) 클레임 발생을 원천 방지하기 위함입니다.
*   **적용**: 패키지 표면 이외의 배경 디자인 영역에 배치된 타이틀, 하단 설명문구, 홍보 태그 등만 일본어로 기획 번역 및 렌더링을 진행합니다.

## 3. 실행 방법 (SOP)

1.  **입력 대기**: 번역할 한국어 이미지 파일(.png 등)을 지정된 대상 폴더에 준비합니다.
2.  **배치 실행**: `run_JP_Ecom_Visual_Localizer_V5.bat` 스크립트를 더블클릭하여 가동하거나 명령 프롬프트에서 아래와 같이 수동 실행합니다:
    ```bash
    python JP_Ecom_Visual_Localizer_V5.py "<KOR 원본 폴더 경로>" "<JP 번역본 결과 폴더 경로>"
    ```
3.  **결과 확인**: 변환된 파일은 지정한 아웃풋 폴더에 `[원본명]_JP_Surgical_v5.png` 형식으로 출력됩니다.
