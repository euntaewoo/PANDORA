## 💬 방법 1. [최우선 권장] 안티그래비티 채팅창 대화 요청 (가장 편리)

터미널을 열거나 명령어를 복사할 필요 없이, 안티그래비티 대화창에 자연어로 말씀하시면 에이전트가 백그라운드에서 무인 자동으로 엔진을 구동하고 품질을 검수하여 보고합니다.

### 🗣️ 대화 요청 예시
- **영어 번역**: `"01_번역대상_원본에 이미지 넣었어. 영어로 번역해줘"`
- **일본어 번역**: `"일본어 약기법 번역 시작해줘"`
- **중국어 간체 번역**: `"중국어 간체로 번역해줘"`
- **중국어 번체 번역**: `"대만 번체로 번역해줘"`
- **전체 일괄 번역**: `"모든 언어로 일괄 번역해줘"`

## 💻 방법 2. 터미널(명령 프롬프트)에서 직접 실행

개발자 환경이나 터미널 창에서 직접 파이썬 명령어를 실행하는 방법입니다.

### 2-1. 대화형 선택 모드 (콘솔 질문에 숫자 입력)
```cmd
:: 상위 프로젝트 루트(C:\Users\euntaewoo\Desktop\다국어_이미지_번역) 기준
.venv\Scripts\python.exe multilingual_text_in_image_translation\multilingual_text_in_image_translation.py
```
- 실행 후 나타나는 콘솔 메뉴에서 번호(`1`: 영어, `2`: 일본어, `3`: 간체, `4`: 번체, `5`: 전체, `Q`: 종료)를 입력하고 엔터를 누릅니다.

### 2-2. 언어 코드 직접 지정 모드 (원클릭 즉시 실행)
```cmd
:: 영어 즉시 실행
.venv\Scripts\python.exe multilingual_text_in_image_translation\multilingual_text_in_image_translation.py --lang EN

:: 일본어 즉시 실행
.venv\Scripts\python.exe multilingual_text_in_image_translation\multilingual_text_in_image_translation.py --lang JP

:: 중국어 간체 즉시 실행
.venv\Scripts\python.exe multilingual_text_in_image_translation\multilingual_text_in_image_translation.py --lang CN

:: 중국어 번체 즉시 실행
.venv\Scripts\python.exe multilingual_text_in_image_translation\multilingual_text_in_image_translation.py --lang TW

:: 전체 언어 순차 일괄 실행
.venv\Scripts\python.exe multilingual_text_in_image_translation\multilingual_text_in_image_translation.py --lang ALL
```

## 🖱️ 방법 3. [차선책] 윈도우 탐색기 더블클릭 런처

마우스 조작만으로 실행할 수 있는 보조 방법입니다.

1. 윈도우 파일 탐색기에서 **`multilingual_text_in_image_translation`** 폴더로 이동합니다.
2. **[`다국어_통합번역_원클릭실행.bat`](file:///C:/Users/euntaewoo/Desktop/다국어_이미지_번역/multilingual_text_in_image_translation/다국어_통합번역_원클릭실행.bat)** 파일을 마우스로 **더블클릭**합니다.
3. 열린 검은색 창(CMD)에서 원하는 언어 번호(`1`~`5`)를 입력하고 엔터를 누릅니다.
