# 🇨🇳 CN_Text-In_Image_Translation_Engine (중국어 이미지 번역 아키텍처)

본 문서는 중화권(중국 본토, 대만, 홍콩) 이커머스 상세페이지 이미지 번역 엔진의 표준 규격서입니다.

---

## 🌟 핵심 운영 원칙 (Core Rules)

### 1. 타겟 권역 사전 확인 의무 규칙 (`[RULE 8]`)
- 사용자가 중국어 번역을 요청할 때, 타겟 권역이 명시되지 않은 경우 에이전트는 절대 임의로 추측(`[ZERO-GUESSING]`)하지 않고 반드시 아래의 표준 질문을 먼저 제시합니다:
  > **"중국 본토(간체자)와 대만/홍콩(번체자) 중 어느 시장을 타겟으로 제작할까요?"**

---

## 🏗️ Two-Pass 아키텍처 및 권역별 특화 규격

```text
[입력 이미지]
     │
     ▼
[Pass 1: Gemini 3.1 Pro] ➔ 텍스트 추출 및 권역별 법률/톤앤매너 매핑 JSON 생성
     │
     ├─ 중국 본토 (CN): 간체자(zh-CN) + 중국 신광고법 절대화 표현(最, 第一 등) 검열
     └─ 대만/홍콩 (TW/HK): 번체자(zh-TW/HK) + 대만/홍콩 현지 뷰티 용어(鎖水, 爽膚水 등)
     │
     ▼
[Pass 2: Gemini 3.1 Flash Image] ➔ 한글 완벽 제거 및 Noto Sans TC / 알리바바 푸후이체 식자 인페인팅
     │                                 (대만/홍콩 모드 시 養/對/護 등 번체자 글리프 잠금 강제)
     ▼
[후처리: Pillow LANCZOS] ➔ 원본 해상도 및 종횡비(Aspect Ratio) 1:1 보존 복원
```

## 📋 상품 정보 고시 표(Notice Table) 렌더링 규격
- **캔버스 규격**: 가로 **`860px` 고정**, 세로 **`Auto-Fit` (최대 허용치 `2,580px` 이하, 초과 시 2페이지 분할)**
- **폰트 규격 (한자 Em-Box 최적화)**:
  - 상단 타이틀 (商品基本信息 등): **`52px` (Bold)**
  - 테이블 좌측 항목명 (라벨 열): **`26px` (Bold, 1열 폭 중화권(간체/번체) `270px`, 좌우 여백 `30px`)**
  - 테이블 우측 본문 내용 (값 열): **`26px` (Regular, 행간 1.65, 순수 본문 폭 `520px`)**
- **공통 렌더러**: `00_공통자료/render_notice_table_standard.py`
- **[지능형 문맥 의미 단위 줄바꿈]**: 
  - 10자 미만 단문 라벨(`使用注意事项` 6자, `消费者咨询电话` 7자 등)은 **100% 1줄 유지**.
  - 10자 이상 복합 라벨(`特殊用途化妆品<br>审查状态`, `化妆品生产企业 /<br>责任销售商`)은 문맥 의미 단위 2줄 황금 분할.
  - 2열 본문 주의사항 끝단 단어 결속(`<span style="white-space: nowrap">`)으로 외톨이 글자(Orphan) 원천 방지.
- **[2열 본문 심사 효능 줄바꿈 규격]**: 특수용도/기능성 심사 2열 본문에서 기관 심사 결과 뒤의 괄호 효능 설명(`(美白...)`, `(미백...)`)은 서로 다른 의미 단위이므로 괄호 `(` 또는 `（` 앞에서 파이썬 렌더러가 100% 강제 줄바꿈(`<br>`) 주입.
- **[고시표 전담 QA 서브에이전트]**: `notice_table_frontend_qa_agent`가 1차 렌더링 즉시 픽셀 단위로 자가 검수 및 자동 교정.

### 💡 실전 번역 적용을 위한 국가별 팁
1. **간체자 권역 (중국 본토, 싱가포르, 말레이시아)**:
   - 싱가포르·말레이시아는 간체자를 사용하지만 중국 본토 전용 정치 용어나 본토 신조어는 배제.
   - 쇼핑몰(Shopee, Lazada)은 영어 상세페이지가 기본이며, 중국어 간체는 보조 언어로 활용.
2. **대만 번체자 권역 (대만)**:
   - 단순 문자 변환기(간체➡️번체) 사용 시 검색 최적화(SEO) 파괴. 대만 전용 어휘(예: `智慧型手機`, `化妝水`, `精華液`, `水光肌`) 적용 필수.
3. **홍콩 번체자 권역 (홍콩, 마카오)**:
   - 대만식 어휘와 차별화된 홍콩식 번체 키워드 적용, 브랜드명 및 핵심 제품 스펙은 영어 원문을 그대로 노출하여 신뢰도 극대화.
